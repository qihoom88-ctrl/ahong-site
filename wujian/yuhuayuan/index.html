三個最常想錯的地方

先把這三件事調回來

這三句話我在現場聽過很多次。不是誰笨，是資訊本來就不好查。

「現況出租中，代表屋況都有人在維護，應該比空屋更好。」 更正：出租中代表有人住，不代表已經整理成交屋狀態，這點是屋況問題。至於入住時程：買賣不破租賃，租賃關係會隨產權移轉給你，但租約2026年8月底到期後就轉為不定期租賃，依委託方說明，售出後一個月內房客會搬離，你的入住時間大約是交屋後一個月。要讓這件事有保障，就在契約裡把遷出時點與空屋點交寫清楚，我會幫你談。看屋當天先跟我約時間，我負責跟房客協調。

租賃狀態與租約條件，簽約前請調閱租約正本確認，以租約正本為準。

「登記28.94坪，就是有28.94坪可以用。」 更正：登記28.94坪裡，主建物16.61坪＋附屬建物3.46坪才是你實際碰得到、用得到的部分，公設8.87坪是分擔的共用部分，公設比30.6%。比價的時候一律用主建坪數去對，拿含公設的登記總坪數去比，算出來的單價會失真。

面積與範圍最終以地政機關登載為準，見地政司數位櫃臺申請謄本與建物測量成果圖。

「格局圖上寫『陽台加凸鐵窗』跟『鐵窗增建』，反正大家都這樣，應該沒差。」 更正：這類增建在市場上確實常見，但常見不代表合法，也不代表沒有查報紀錄的風險。這件事我不猜、不背書，查證方式與新北市違章建築查詢入口都在下面「缺點我先講完」第2條，自己查最準。

缺點 01現況出租中：租約8月底到期，售出後一個月內房客搬離
不處理的風險這間現況出租中，租約2026年8月底到期，之後轉為不定期租賃；依委託方說明，售出後一個月內房客會搬離。買賣不破租賃仍然成立，租賃關係會隨產權移轉給買方——如果沒有在契約裡把遷出時點、空屋點交寫清楚，交屋當下對不上會措手不及；押金與已收租金若沒在交屋時書面點交清楚，日後也容易產生爭議。
查證或維修策略
  1. 簽約前調閱租約正本，確認租期到2026年8月底、押金金額、有無優先承購權或續約條款。
  2. 向委託方確認：租約到期後未另訂新約即轉為不定期租賃，售出後一個月內房客搬離的安排，把這個時點寫進契約（例如約定交屋前完成空屋點交，或保留部分價金至房客實際遷出後付清）。
  3. 向委託方確認押金與已收租金的移轉方式，交屋時要有書面點交。
  4. 看屋前先跟我約時間，我負責跟房客協調——現在就可以看，不是要等到房客搬走才能看。
參考費用無修繕費用，屬交易條件，不進本頁修繕合計。
驗屋建議房客在租期間，現況驗屋要配合房客時間安排；與屋齡有關的檢測項目（見缺點04）不受此影響，仍可先討論規劃。
買方對策預算：不計入修繕合計；依委託方說明，售出後一個月內房客會搬離，你的入住時間大約是交屋後一個月，這是明確可規劃的時程，不需要另外編時間成本。
交易結構：把遷出時點與空屋點交寫進契約——例如約定交屋前完成空屋點交，或保留部分價金至房客實際遷出後付清，讓「一個月內搬離」這件事從口頭安排變成有保障的條款。
處理順序：簽約前把租約看過、押金金額對過，把遷出與點交條款排進契約草案，排在其他工項之前。
阿宏協助：審租約重點、安排房客配合看屋、把遷出時點與空屋點交條款寫進要約或契約建議、交屋清點。
缺點 02陽台加凸鐵窗＝增建：格局圖上原有標註，合法性待查證
不處理的風險格局圖上「陽台加凸鐵窗」與「鐵窗增建」是委託銷售資料上原有的標註，不是我事後加的。是否屬違章建築、有無被查報紀錄，簽約前沒查證就簽下去，一旦日後接到拆除通知，那塊使用空間跟拆除清運費會一起沒了；銀行估價通常也不會採計外推部分，自備款可能比想的多。
查證或維修策略
  1. 用「新北市違章建築案件查詢」查有無查報紀錄。
  2. 申請建物謄本，核對主要用途與建物型態，比對現況。
  3. 申請測量成果圖，比對圖面登記範圍與現況鐵窗增建部分是否一致。
  4. 簽約前請地政士協助確認上述三項文件與現況是否一致。
合法與否由主管機關認定，本頁不代為判斷。

處理順序：查證排在簽約前，跟其他謄本查證一起做，不要等交屋後才查。

缺點 03只有一套衛浴：3房2廳的產品定位，不是損壞
不處理的風險3房2廳只配1套衛浴，人口數多或作息時間重疊的家庭，尖峰時段會卡；這不是故障，是這間房子的產品定位——想增設第二套是改造工程不是修繕，要動到給排水與防水，費用與工期都不小。
查證或維修策略
  1. 先用家人作息錯開解決，很多3房家庭其實用得下來。
  2. 真的要增設，位置要靠近既有污水管，得請水電與泥作到現場看過才能判斷可不可行。
  3. 也可以先住一陣子，真的卡再決定要不要做。
參考費用增設第二套衛浴屬改造工程不是修繕，不計入本頁修繕合計；若要做，費用以現場估價為準，本頁不編造數字。
驗屋建議驗屋時請師傅確認既有污水管位置與管徑，這個資訊會直接影響第二套衛浴做不做得成、要花多少。
買方對策預算：不計入修繕合計；真的要做就另編改造預算，先問水電估價再決定。
交易結構：這是買方自己的規劃，跟賣方無關，不需要寫進契約。
處理順序：若要做，建議跟缺點04的管線檢測排在同一趟，入住前一次做完。
阿宏協助：代約水電與泥作到場評估可行性、比對報價單。
缺點 04屋齡30年，現場可見多處老化痕跡，管線防水沒有複驗紀錄
不處理的風險民國84年10月完工，屋齡30年。從實拍照片就看得到幾處老化痕跡：主臥天花板有一條髮絲裂縫、工作陽台天花板轉角批土剝落、陽台鐵窗雨遮支架生鏽、小臥室房門片掉漆——這些是照片上看得到的部分，畫面裡的家具家電是房客的，不算在屋況內。另外，客廳與主臥牆面近天花板處有深淺不均，照片受光線與陰影影響無法判斷是單純髒污還是水氣痕跡，這條不預設是漏水，需現場複驗確認。給排水管線、配電迴路與防水層這類看不到的部分，屋齡到了也可能已達更新年限。沒有提前檢查跟處理，輕則要花更多錢重做，重則交屋後才發現跳電、滲漏。屋齡到了，浴室照明／通風設備這類本來就會逐年更換，是正常耗損不列為本頁缺點。
查證或維修策略
  1. 先請水電師傅到現場做電路檢測，評估迴路容量夠不夠、老線要不要換。
  2. 視結果決定是否局部換管、或為高耗電設備加裝專用迴路。
  3. 衛浴與廚房周邊做一次漏水檢查，牆面深淺不均處與地磚縫隙偏深色是滲水、壁癌還是單純髒污，讓師傅現場判斷，不是看照片猜。
  4. 天花板裂縫與陽台批土剝落處，請泥作或油漆師傅局部批土上漆；房門片重新粉刷；陽台鐵窗雨遮鐵件除鏽另外估價。
  5. 先做檢測與局部整理再決定要不要全面翻新，不要一開始就編整包裝修預算。
