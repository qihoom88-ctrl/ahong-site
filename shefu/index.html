✓ 家中目前是低收入戶，正在領家庭、兒童或就學生活補助
✓ 家中有身心障礙者，目前正在領取生活補助費
✓ 家中有符合中低收入資格的長者，正在領老人生活津貼
✓ 正在照顧經地方政府核定的弱勢兒童或少年
✓ 家中有人正在領國民年金基本保障類給付，或即將年滿 65 歲
✓ 過去曾因所得、財產、戶籍或文件問題未通過，想重新確認資格

最終仍須依各項補助的年齡、所得、財產、戶籍、家庭人口與文件規定審查 各縣市受理方式可能不同
